# РУСИТ 5.0 — Полная спецификация
## Ревизия 2 (с учётом всех 30 исправлений)

**Радикально-аналитический язык на основе русской лексики**

---

## §0. Основные принципы

### 0.1. Определение

РУСИТ — искусственный аналитический язык, использующий русскую лексику в неизменяемой форме. Все грамматические значения передаются служебными словами, порядком слов и контекстом.

### 0.2. Главный закон

> **Лексема не изменяется по грамматическим категориям.**
> **Грамматические значения выражаются служебными словами, порядком слов и контекстом.**

### 0.3. Приоритеты

> **Регулярность важнее узнаваемости.**
> **Исключений нет.**

### 0.4. Область применения принципа «0 исключений»

> **Нулевая исключительность относится к грамматике РУСИТ, а не к внутренней морфологии исходных русских лексем.** Лексическая омонимия, супплетивизм и нерегулярные основы русского языка сохраняются как лексические факты, но не порождают грамматических исключений.

### 0.5. Разрешено и запрещено

| Запрещено | Разрешено |
|---|---|
| Флексия (склонение, спряжение) | Деривация (словообразование) |
| Согласование | Аналитические конструкции |
| Падежные окончания | Предлоги и частицы |
| Родовые окончания | Неизменяемая лексема |
| Любые грамматические исключения | Полная регулярность |

### 0.6. Типологический профиль

| Параметр | Значение |
|---|---|
| Тип | Радикально аналитический язык с единственным продуктивным грамматическим аффиксом |
| Порядок слов | Базовый SVO; топикализация допускает отклонения |
| Флексия | 0 |
| Агглютинация | 0 |
| Продуктивные аффиксы | 1 (императивный суффикс, 2 алломорфа) |
| Исключения | 0 |
| Тоны | Нет |
| Грамматический род | Нет |
| Падежи | Нет (заменены предлогами) |
| Спряжение | Нет |
| Согласование | Нет |
| Артикли | Нет (определители: один / этот / тот) |

## §1. Лексема

### 1.1. Каноническая форма

У каждого слова есть **одна неизменяемая форма**.

| Часть речи | Каноническая форма | Пример |
|---|---|---|
| Существительное | Именительный ед. ч. | дом, человек, море |
| Прилагательное | Основа (кач.) / полная (отн.) | больш, красив, деревянный |
| Глагол | Основа без инфинитивного суффикса | чита, говори, иди |
| Местоимение | Именительный | я, ты, он, она, мы, вы, они |
| Числительное | Базовая форма | один, два, три, десять |

## §2. Глагольная лексема

### 2.1. Правила образования (0 исключений)

| Окончание инфинитива | Правило | Пример |
|---|---|---|
| **-ть** | убрать `-ть` | читать → **чита**, говорить → **говори**, делать → **дела** |
| **-ти** | заменить на `-и` | идти → **иди**, нести → **неси**, плести → **плети** |
| **-чь** | всегда заменить на `-г` | беречь → **берег**, мочь → **мог**, течь → **тег**, печь → **пег** |
| **-сть** | всегда заменить на `-д` | красть → **крад**, пасть → **пад**, сесть → **сед** |

### 2.2. Правило эпентезиса

> Если после удаления инфинитивного маркера основа представляет собой **один открытый слог** (согласный + гласная) и/или **совпадает со служебным словом или местоимением РУСИТ**, к основе добавляется эпентетический суффикс **-ти**.

| Инфинитив | Основа | Совпадение | Лексема |
|---|---|---|---|
| пить | пи | один открытый слог | **пити** |
| бить | би | би = пассивный маркер | **бити** |
| шить | ши | один открытый слог | **шити** |
| мыть | мы | мы = местоимение | **мыти** |
| выть | вы | вы = местоимение | **выти** |
| дать | да | да = императивная частица | **дати** |
| есть₁ (кушать) | е | один открытый слог | **ести** |

### 2.3. Возвратные глаголы

> При образовании лексемы возвратного глагола исходный **-ся / -сь** удаляется из основы и заменяется отдельной частицей **ся**, которая ставится после глагола.

| Инфинитив | Основа | Лексема | В предложении |
|---|---|---|---|
| умываться | умыва- | **умыва** | он умыва **ся** |
| смеяться | смея- | **смея** | она смея **ся** |
| бояться | боя- | **боя** | я боя **ся** |
| встречаться | встреча- | **встреча** | мы встреча **ся** |
| открываться | открыва- | **открыва** | дверь открыва **ся** |

### 2.5. Видовые пары и лексические различия

> **Грамматическое противопоставление вида нейтрализуется. Разные русские лексемы сохраняются только при различии лексического значения.**

| Русский | РУСИТ | Причина |
|---|---|---|
| читать / прочитать | **чита** | видовая пара, одно значение |
| делать / сделать | **дела** | видовая пара, одно значение |
| писать / написать | **писа** | видовая пара, одно значение |
| строить / построить | **строи** | видовая пара, одно значение |
| говорить / сказать | **говори** / **сказа** | разные лексические значения |
| идти / ходить | **иди** / **ходи** | разные лексические значения |
| войти / выйти | **войди** / **выйди** | разные лексические значения |

### 2.6. Глагол `быть`

> **Глагол `быть` в РУСИТ отсутствует как самостоятельная лексема.** Его функции распределены между грамматическими маркерами:
> - Прошедшее время → частица **был**
> - Будущее время → частица **буд**
> - Условие → частица **бы**
> - Существование → экзистенциальный предикатор **есть₂**

> **`был`, `буд`, `бы` являются самостоятельными грамматическими маркерами и НЕ являются формами глагола `быть`.**

### 2.7. Глагол `есть`

> **есть₁** (кушать) → глагольная лексема **ести**
> **есть₂** (существовать) → экзистенциальный предикатор **есть** (неизменяемый служебный элемент)

| Конструкция | Значение |
|---|---|
| я ести яблоко | я ем яблоко |
| у я есть дом | у меня есть дом |
| в лес есть волк | в лесу есть волк |

## §3. Существительное

### 3.1. Неизменяемость

Существительное **не имеет** падежа, числа, рода.

> дом = дом, дома, дому, домом, о доме

### 3.2. Число

| Значение | Средство | Пример |
|---|---|---|
| Неопределённое | Нулевая форма | дом |
| Единственное | один | один дом |
| Множественное | много / числительное / все | много дом, три дом, все дом |

При числительных существительное **всегда** в базовой форме:

> один дом, два дом, три дом, сто дом, тысяча дом

### 3.3. Определённость

> Артиклей нет. `один`, `этот`, `тот` выполняют функции **определителей**.

| Определитель | Функция | Пример |
|---|---|---|
| один | новый, неопределённый | один человек приходи |
| этот | конкретный, идентифицированный | этот человек сиди |
| тот | удалённый, известный из контекста | тот дом стоя на гора |
| ∅ | нейтральный | дом стоя в лес |

## §4. Местоимение

### 4.1. Базовые формы

| Лицо | Форма |
|---|---|
| 1 ед. | я |
| 2 ед. | ты |
| 3 ед. м. | он |
| 3 ед. ж. | она |
| 3 ед. ср. | оно |
| 1 мн. | мы |
| 2 мн. | вы |
| 3 мн. | они |

> Грамматического рода нет. Лексическое различение пола/референта в третьем лице сохраняется.

### 4.2. Косвенные роли

| Русский | РУСИТ |
|---|---|
| мне | к я |
| мной | с я |
| мой / у меня | у я |
| ему | к он |
| ею | с она |
| их | от они |

### 4.3. Указательные и вопросительные

Неизменяемы:

> этот, тот, такой, здесь, там
> кто, что, какой, где, когда, почему, зачем, как, сколько

## §5. Прилагательное

### 5.1. Неизменяемость

Прилагательное **никогда не согласуется**:

> больш дом, больш машина, больш окно, больш люди

### 5.2. Два типа

**Качественные** (усечённые) — каноническая основа:

| Русский | РУСИТ |
|---|---|
| большой | больш |
| красивый | красив |
| новый | нов |
| старый | стар |
| тихий | тих |
| холодный | холодн |
| тёмный | тёмн |
| маленький | мал |
| быстрый | быстр |

> **Каноническая лексема качественного прилагательного = неизменяемая основа, исторически совпадающая или близкая к основе русского прилагательного.** Это не «краткая форма», а самостоятельная лексема РУСИТ.

**Относительные** (полная форма) — без изменений:

| Русский | РУСИТ |
|---|---|
| деревянный | деревянный |
| лесной | лесной |
| каменный | каменный |
| железный | железный |
| научный | научный |
| русский | русский |
| городской | городской |
| музыкальный | музыкальный |

### 5.3. Определение типа

> **Тип прилагательного (качественное / относительное) является лексической характеристикой словаря РУСИТ.** Он не вычисляется носителем каждый раз.

### 5.4. Функция наречия

Отдельного класса наречий нет. Прилагательное становится наречием по позиции:

| Позиция | Функция | Пример |
|---|---|---|
| Перед существительным | прилагательное | тих человек |
| После глагола | наречие | он говори тих |

### 5.5. Степени сравнения

| Степень | Средство | Пример |
|---|---|---|
| Положительная | ∅ | больш |
| Сравнительная | более | более больш |
| Превосходная | самый | самый больш |

## §6. Числительное

### 6.1. Неизменяемость

Числительное не склоняется и не требует изменения существительного:

> один дом, два дом, три дом, сто дом

### 6.2. Составные числа

| Число | РУСИТ |
|---|---|
| 11 | десять один |
| 20 | два десять |
| 100 | сто |
| 200 | два сто |
| 1000 | тысяча |
| 2024 | два тысяча два десять четыре |

### 6.3. Порядковые

> дом номер один = первый дом
> этаж номер два = второй этаж

### 6.4. Дроби

> один из два = 1/2
> три из четыре = 3/4

---

## §7. Глагол: время, вид, фаза

### 7.1. Неизменяемость

Глагол **не изменяется** по лицу, числу, роду, времени, наклонению.

> я говори, ты говори, он говори, мы говори

### 7.2. Время

| Время | Частица | Пример | Перевод |
|---|---|---|---|
| Настоящее | ∅ | я чита | я читаю |
| Прошедшее | был | я был чита | я читал |
| Будущее | буд | я буд чита | я буду читать |

### 7.3. Вид и завершённость

| Тип | Частица | Пример | Перевод |
|---|---|---|---|
| Несовершённый | ∅ | я чита | я читаю |
| Совершённый (телический) | кон | я кон чита | я прочитал |
| Результат (приобретение) | получ | я получ зна | я узнал |
| Результат (утрата) | перест | я перест люби | я разлюбил |

### 7.4. Фаза

| Фаза | Частица | Пример | Перевод |
|---|---|---|---|
| Начало | нач | я нач чита | я начинаю читать |
| Прекращение | пере | я пере чита | я перестаю читать |
| Продолжение | прод | я прод чита | я продолжаю читать |

### 7.5. Прогрессив и экспериенциальность

| Категория | Частица | Пример | Перевод |
|---|---|---|---|
| Прогрессив | сей | я сей чита | я сейчас читаю |
| Опыт | про | я про чита | я когда-то читал |

### 7.6. Мутатив

> **ста** + прилагательное = изменение физического или эмоционального состояния.
> **станов** + существительное = приобретение социальной роли, профессии или статуса.

| Конструкция | Частица | Пример | Перевод |
|---|---|---|---|
| ста + прилагательное | ста | город ста тих | город стал тихим |
| станов + существительное | станов | она станов врач | она стала врачом |

### 7.7. Возвратность

Частица **ся** ставится после глагола:

> он умыва ся = он умывается
> дверь открыва ся = дверь открывается
> они встреча ся = они встречаются

### 7.8. Шаблон глагольной группы

```
[не] [был|буд] [про|сей] [кон|нач|пере|прод|получ|перест] [ста|станов] V [ся]
```

## §8. Императив

### 8.1. Главный принцип

Императив образуется **аналитически**. Суффикс используется **только для 2-го лица единственного числа**. Все остальные лица — через отдельные слова.

### 8.2. Императив 2-го лица единственного (ты)

**1 императивный суффикс с двумя алломорфами:**

| Окончание лексемы | Алломорф | Пример |
|---|---|---|
| **Гласная** (-а, -е, -о, -у, -я) | **-й** | чита → **читай**, дела → **делай**, работа → **работай** |
| **Гласная** (-и) | **без изменений** | говори → **говори**, иди → **иди**, люби → **люби** |
| **Согласная** | **-и** | берег → **береги**, крад → **кради**, мог → **моги** |

### 8.3. Императив 2-го лица множественного / вежливое (вы)

Императив (ты) + слово **вы**:

| Ты | Вы |
|---|---|
| читай | **читай вы** |
| говори | **говори вы** |
| береги | **береги вы** |
| кради | **кради вы** |

### 8.4. Императив 1-го и 3-го лица

Частица **да** + подлежащее + лексема (без суффиксов):

| Лицо | Конструкция | Пример | Перевод |
|---|---|---|---|
| мы | да мы + лексема | **да мы чита!** | Давайте читать! |
| он/она | да он/она + лексема | **да он говори!** | Пусть говорит! |
| они | да они + лексема | **да они иди!** | Пусть идут! |

### 8.5. Отрицательный императив

> не читай! = Не читай!
> не говори! = Не говори!
> не читай вы! = Не читайте!
> да мы не чита! = Давайте не читать!

### 8.6. Полная парадигма

| Инфинитив | Лексема | Индикатив | Императив (ты) | Императив (вы) | Императив (он) |
|---|---|---|---|---|---|
| читать | чита | я чита | **читай!** | **читай вы!** | да он чита! |
| говорить | говори | я говори | **говори!** | **говори вы!** | да он говори! |
| делать | дела | я дела | **делай!** | **делай вы!** | да он дела! |
| идти | иди | я иди | **иди!** | **иди вы!** | да он иди! |
| любить | люби | я люби | **люби!** | **люби вы!** | да он люби! |
| писать | писа | я писа | **писай!** | **писай вы!** | да он писа! |
| строить | строи | я строи | **строи!** | **строи вы!** | да он строи! |
| пить | пити | я пити | **пити!** | **пити вы!** | да он пити! |
| беречь | берег | я берег | **береги!** | **береги вы!** | да он берег! |
| красть | крад | я крад | **кради!** | **кради вы!** | да он крад! |
| мочь | мог | я мог | **моги!** | **моги вы!** | да он мог! |

### 8.7. Различение индикатива и императива

| Конструкция | Структура | Пример | Значение |
|---|---|---|---|
| Индикатив | Подлежащее + лексема | я говори | я говорю |
| Императив 2 л. | Лексема без подлежащего (+ суффикс) | говори! / читай! | говори! / читай! |
| Императив 1/3 л. | да + подлежащее + лексема | да он говори! | пусть говорит! |

Для глаголов на **-и** омонимия индикатива и императива сохраняется, но разрешается **синтаксисом** и **интонацией**.

## §9. Отрицание

Частица **не** ставится перед первым глагольным элементом:

> я не говори
> он не был чита книга
> мы не буд иди
> я не кон дела работа

С именной частью:

> я не врач
> она не красив

---

## §10. Вопрос

### 10.1. Полярный вопрос (да/нет)

Частица **ли** в абсолютном начале:

> ли ты люби этот книга?
> ли он был дома?
> ли вы буд иди?

### 10.2. Вопрос с вопросительным словом

**ли** не используется. Вопросительное слово в начале:

> кто ты види?
> что он дела?
> где ты живи?
> когда они буд иди?
> почему ты не говори?

### 10.3. Встроенный полярный вопрос

**ли** маркирует встроенный вопрос да/нет:

> я не зна ли он буд приходи

### 10.4. Встроенный вопрос с WH-словом

**ли** не используется:

> я не зна кто он види

---

## §11. Условие и сослагательность

Частица **бы** после подлежащего:

> я бы иди = я бы пошёл
> если я зна, я бы приходи = если бы я знал, я бы пришёл

| Конструкция | Пример | Перевод |
|---|---|---|
| надо + S + V | надо я иди | мне надо идти |
| можно + S + V | можно ты входи | можно тебе войти |
| нельзя + S + V | нельзя они говори здесь | им нельзя здесь говорить |

## §13. Падежные отношения

### 13.1. Предлоги (8)

| Предлог | Функция | Пример | Перевод |
|---|---|---|---|
| у | принадлежность | книга у я | моя книга |
| от | источник / происхождение | подарок от мама | подарок от мамы |
| к | адресат / направление | я идти к дом | я иду к дому |
| с | инструмент / совместность | я пиши с ручка | я пишу ручкой |
| в | место (внутри) | в дом | в доме |
| на | место (поверхность) | на стол | на столе |
| из | исходный пункт | из город | из города |
| о | тема | говори о война | говорить о войне |

### 13.2. Пассивный агентивный маркер (1)

| Маркер | Функция | Пример | Перевод |
|---|---|---|---|
| би | агент пассива | строи би рабочий | построен рабочими |

### 13.3. Экзистенциальный предикатор (1)

| Маркер | Функция | Пример | Перевод |
|---|---|---|---|
| есть₂ | существование / наличие | у я есть дом | у меня есть дом |

### 13.4. Разграничение у / от

| | у | от |
|---|---|---|
| Значение | Принадлежность лицу | Источник, происхождение |
| Пример | книга у я | письмо от я |
| Перевод | моя книга | письмо от меня |

### 13.5. Посессивность

> **X у Y = X принадлежит Y.**
> Цепочка **X у Y у Z** интерпретируется **слева направо**:
> дом у брат у друг = дом, принадлежащий брату, который принадлежит другу.

### 13.6. Локатив / директив

> Предлоги РУСИТ кодируют **семантические отношения**. Локативное или директивное значение определяется **глаголом и контекстом**.

> я иди в дом = я иду в дом (направление)
> я живи в дом = я живу в доме (место)
> книга на стол = книга на столе (место)

---

## §14. Пассив

### 14.1. Конструкция

> Пациент + TAM + кон + V + би + агент

> дом был кон строи би рабочий = дом был построен рабочими
> книга буд кон чита би ученик = книга будет прочитана учеником

### 14.2. Без агента

> дом был кон строи = дом был построен
> книга кон чита = книга прочитана

---

## §15. Придаточные предложения

### 15.1. Изъяснительные (что)

> я зна что он живи Москва = я знаю, что он живёт в Москве

### 15.2. Относительные (который)

> **Относительное местоимение `который` не изменяется по синтаксической роли. Его роль определяется позицией в относительном предложении.**

| Конструкция | Роль «который» | Перевод |
|---|---|---|
| человек который я люби | объект | человек, которого я люблю |
| человек который люби я | субъект | человек, который любит меня |
| книга который я чита | объект | книга, которую я читаю |

### 15.3. Замена причастий

> человек, который сиди у окно = человек, сидящий у окна

### 15.4. Замена деепричастий

> когда она улыба, она был кон войди в комната = Улыбаясь, она вошла в комнату.

---

## §16. Порядок слов

### 16.1. Базовый порядок

```
[Время] – S – TAM – V – O – [Место] – [Способ]
```

> я вчера был кон чита этот книга в дом

### 16.2. Позиции обстоятельств

| Тип | Позиция | Пример |
|---|---|---|
| Время | Абсолютное начало ИЛИ после объекта | вчера я чита / я чита вчера |
| Место | Только после объекта | я чита в дом |
| Способ | Только после объекта и места | я чита в дом тихо |

### 16.3. Топикализация

Вынесенный объект маркируется позицией:

> этот книга я чита = книгу я читаю

### 16.4. Правила

- Подлежащее перед глаголом
- Объект после глагола
- Определение перед определяемым
- Обстоятельство после объекта
- Топикализация допускает вынос объекта в начало

## §17. Союзы и относительные местоимения

### 17.1. Союзы (9)

Неизменяемы:

> и, но, или, а, что, чтобы, если, когда, хотя

### 17.2. Относительное местоимение (1)

> который

### 17.3. Примеры

> я чита книга, потому что я люби книга
> если ты буд иди, я буд иди с ты
> человек который я люби

## §21. Правила совместимости частиц

### 21.1. Взаимоисключающие пары времени

> **был и буд взаимоисключающие.**

### 21.2. Запрещённые пары

| Пара | Причина |
|---|---|
| кон + нач | взаимоисключающие границы |
| кон + пере | взаимоисключающие границы |
| кон + прод | взаимоисключающие границы |
| нач + пере | взаимоисключающие границы |
| нач + прод | взаимоисключающие границы |
| пере + прод | взаимоисключающие границы |
| про + кон | опыт не совместим с завершённостью |
| про + нач | опыт не совместим с началом |
| про + пере | опыт не совместим с прекращением |
| про + прод | опыт не совместим с продолжением |
| про + сей | опыт не привязан к моменту |
| про + ста | опыт не применим к смене состояния |
| сей + прод | избыточно |
| сей + кон | прогрессив несовместим с завершённостью |
| ста + кон | мутатив уже содержит результативность |
| ста + нач | «начать стать» противоречиво |

### 21.3. Разрешённые комбинации

| Комбинация | Пример | Перевод |
|---|---|---|
| был + сей | я был сей чита | я в тот момент читал |
| буд + сей | я буд сей чита | я буду в этот момент читать |
| был + кон | я был кон чита | я прочитал |
| буд + кон | я буд кон чита | я прочитаю |
| был + нач | я был нач чита | я начинал читать |
| не + был | я не был чита | я не читал |
| не + буд | я не буд чита | я не буду читать |

### 21.4. Общее правило

> **Не более одной граничной частицы (кон/нач/пере/прод/получ/перест) на глагол.**
