# РУСИТ 5.3.1 — Полная спецификация

**Радикально-аналитический язык на основе русской лексики**  

---

## §0. Основные принципы

### 0.1. Определение

РУСИТ — искусственный аналитический язык, использующий русскую лексику в неизменяемой форме. Все грамматические значения передаются служебными словами, жёстким порядком слов и контекстом.

### 0.2. Главный закон

> **Лексема не изменяется по грамматическим категориям.**  
> **Грамматические значения выражаются служебными словами, порядком слов и контекстом.**

### 0.3. Приоритеты

> **Регулярность грамматики важнее узнаваемости отдельных слов.**  
> **Исключений в грамматике нет.**

### 0.4. Разрешено и запрещено

| Запрещено | Разрешено |
|---|---|
| Флексия: склонение, спряжение, согласование | Деривация: словообразование вне грамматики |
| Падежные окончания | Реляционные слова: предлоги и аналоги |
| Родовые и числовые окончания | Неизменяемая лексема |
| Грамматические исключения | Полная регулярность грамматических операций |

### 0.5. Типологический профиль

| Параметр | Значение |
|---|---|
| Тип | Аналитический / изолирующий |
| Порядок слов | Жёсткий SVO с факультативной топикализацией |
| Флексия | 0 |
| Грамматические суффиксы | 0 |
| Лексическая деривация | Допустима; в грамматические операции не входит |
| Лексика | Русская, канонизируемая словарём |
| Артикли | Отсутствуют; `этот` / `тот` — указательные |
| Род | Отсутствует |
| Падежи | Отсутствуют; заменены реляционными словами |
| Спряжение | Отсутствует |
| Грамматические исключения | Отсутствуют |
| Лексические нерегулярности | Допускаются только как факты словаря |

### 0.6. Четырёхуровневая архитектура

| Уровень | Содержание | Носитель |
|---|---|---|
| 1. Лексический | Канонические лексемы | `rusit_lexicon.db` |
| 2. Грамматический | TAM, вид, фаза, результативность, мутатив, отрицание, возвратность, модальность | частицы уровней 1–3, §20 |
| 3. Синтаксический | SVO, пассив, вопросы, придаточные, императив, посессив, топикализация | §8–§18 |
| 4. Дискурсивный | Фокус, кванторы, темпоральные модификаторы, разговорные маркеры, регистры | частицы уровней 0–2, §22 |

Схема словаря `rusit_lexicon.db` будет опубликована в приложении к следующей редакции; настоящая спецификация определяет состав словарных данных, но не формат файла.

### 0.7. Область регулярности

> Отсутствие исключений относится к **грамматике** РУСИТ. Лексические чередования, супплетивизм, нерегулярные основы и наличие/отсутствие форм у отдельных слов являются свойствами исходной лексики и фиксируются в словаре.

- **Грамматические операции** абсолютно регулярны.
- **Каноническая форма слова** — факт словаря.
- Разметка R/N/L в §2.4 показывает происхождение каждой лексемы: регулярное (R), от настоящего времени (N) или словарное (L). Это не исключения, а прозрачность словаря.

## §1. Лексема

### 1.1. Каноническая форма

У каждого слова есть **одна неизменяемая форма** — запись в словаре.

| Часть речи | Каноническая форма | Пример |
|---|---|---|
| Существительное | Именительный ед. ч. | дом, человек, море |
| Прилагательное | Полная форма м. р. ед. ч. им. п. | большой, красивый, деревянный |
| Глагол | Каноническая лексема словаря | чита, говори, иди |
| Местоимение | Именительный | я, ты, он, она, мы, вы, они |
| Числительное | Базовая форма | один, два, три, десять |
| Указательное слово | Базовая форма | этот, тот, здесь, там |
| Наречие времени | Базовая форма (закрытый список) | вчера, сейчас, никогда |

### 1.2. Лексические классы

Грамматических наречий как класса нет (§5.3). Существуют:

- **указательные слова**: `этот, тот, такой, здесь, там` и др. (§4.3);
- **закрытый список наречий времени**: `вчера, сегодня, сейчас, завтра, потом, всегда, никогда` (§5.3). Список закрыт: новые элементы не образуются, другие темпоральные значения выражаются именными группами (`этот день`, `прошлый год`).
- **служебная лексема `есть`** (экзистенциальная, §2.4).

## §2. Глагольная лексема

### 2.1. Лексическая канонизация

Каноническая форма глагола — **факт словаря**, а не результат грамматической операции. Словарь хранит для каждого глагола одну неизменяемую лексему.

Разведены два понятия:

- **лексическая канонизация** — выбор неизменяемой формы; решает словарь;
- **грамматическая обработка** — время, вид, фаза, результативность, мутатив, возвратность; решают частицы.

### 2.2. Правила построения словарных записей

При добавлении нового глагола используются пять правил. Правила **не заменяют словарь**: при расхождении нормативна словарная запись.

> **Правило 1 (регулярные -ать/-еть/-ить).** Лексема = инфинитив без `-ть`: читать → **чита**, говорить → **говори**, знать → **зна**.

> **Правило 2 (основа настоящего времени).** Глаголы с чередованием основ: лексема = основа настоящего времени: спать → **спи** (сп-и-шь), жить → **живи**, смотреть → **смотри**.

> **Правило 3 (короткие основы -ти).** Основа короче трёх фонем → инфинитивная основа + `-и`: пить → **пити**, дать → **дати**, есть → **ести**.

> **Правило 4 (суффиксы -ова-, -ыва-).** Суффиксы сохраняются: телефоновать → **телефонова**, доказывать → **доказыва**.

> **Правило 5 (неравномерные -ти).** Для глаголов на -ти с неправильным спряжением лексема = основа настоящего времени + и: идти → ид-и → **иди**, нести → нес-и → **неси**, плести → плет-и → **плети**, грести → греб-и → **греби**, мести → мет-и → **мети**, вести → вед-и → **веди**, ползти → полз-и → **ползи**, расти → раст-и → **расти**.

Глаголы, подпадающие под правила 1–4, под правило 5 не подпадают.

Известные расхождения эвристик, зафиксированные словарём:

| Инфинитив | Правила дают | Лексема словаря |
|---|---|---|
| писать | пиш (пр. 2) | **писа** |
| любить | любь (пр. 2) | **люби** |
| слышать | слышь (пр. 2) | **слыши** |

Это не грамматические исключения: это лексические факты русского языка.

### 2.3. Видовые пары → одна лексема

Для видовой пары словарь задаёт **одну общую каноническую лексему**; завершённость передаётся частицей **кон** (§7.3).

```
читать / прочитать   → чита
писать / написать    → писа
делать / сделать     → дела
говорить / сказать   → говори
строить / построить  → строи
спасать / спасти     → спаса        (кон спаса = спасти)
ловить / поймать     → лови         (кон лови = поймать)
брать / взять        → бери         (кон бери = взять)
идти / прийти        → иди          (кон иди = прийти)
```

Отдельными лексемами остаются производные с семантически значимыми приставками: приходить → **приходи**, уходить → **уходи**, достроить → **дострои**. Это словообразование и лексическая семантика, а не видовая пара.

> он кон спаса ребёнок = он спас ребёнка  
> я кон бери книга = я взял книгу

### 2.4. Стартовый глагольный словарь

**Легенда разметки:**

- **R** — регулярно выводится правилами 1–5 §2.2;
- **N** — лексема = основа **1-го лица** настоящего времени (прямое расширение правила 2);
- **L** — словарная (лексикализованная): не выводится правилами, фиксируется словарём.

Лексема не должна быть омоформой грамматического маркера: например, для `мочь` форма 1-го лица `мог` отвергнута, потому что совпала бы с формой прошедшего времени; словарь фиксирует **мож** (L).

## §3. Существительное

### 3.1. Неизменяемость

Существительное не имеет падежа, числа, рода и согласования.

> дом = дом, дома, дому, домом, о доме

### 3.2. Число

| Значение | Средство | Пример |
|---|---|---|
| нейтральное / неопределённое | нулевая форма | дом |
| единственное (эксплицитное) | `один` | один дом |
| множественное | `много`, числительное, `все` | много дом, три дом, все дом |

`один` — числительное, а не артикль; оно эксплицирует ровно одну единицу. При числительных существительное всегда в базовой форме:

> один дом, два дом, три дом, сто дом, тысяча дом

`много` перед существительным маркирует множественность; перед глаголом или прилагательным маркирует высокую степень (§1.2):

> много дом стоя на гора = много домов стоит на горах  
> я много чита = я много читаю

### 3.3. Определённость

Артиклей в РУСИТ нет. Определённость выражается контекстом и указательными словами:

| Средство | Функция | Пример |
|---|---|---|
| нулевой маркер | нейтральная или неопределённая референция | человек приходи = приходит/приходил человек |
| `этот` | активная, ситуативная идентификация | этот человек сиди = этот человек сидит |
| `тот` | дистальная или анафорическая идентификация | тот дом стоя на гора = тот дом стоял на горах |

## §4. Местоимение и указательные слова

### 4.1. Личные местоимения

| Лицо | Форма |
|---|---|
| 1 ед. | я |
| 2 ед. | ты |
| 3 ед. м. | он |
| 3 ед. ж. | она |
| 3 ед. ср. | оно |
| 1 мн. | мы |
| 2 мн. | вы |
| 3 мн. | они |

### 4.2. Косвенные роли

Притяжание лица выражается через `у`; источник и отделение — через `от`; адресат — через `к`; инструмент/сопровождение — через `с`.

| Русский | РУСИТ |
|---|---|
| мне | к я |
| мной / со мной | с я |
| мой / у меня | у я |
| ему | к он |
| ею / с ней | с она |
| письмо от них | письмо от они |
| их книга | книга у они |
| её дом | дом у она |

Разграничение принципиально: `у NP` — обладание, `от NP` — источник или отделение. Смешение функций недопустимо (§13.2).

### 4.3. Указательные и вопросительные слова

Неизменяемы:

> этот, тот, такой, здесь, там  
> кто, что, какой, чей, где, куда, откуда, когда, почему, зачем, как, сколько

> куда ты иди? = куда ты идёшь?  
> откуда он приходи? = откуда он приходит / пришёл (по контексту)  
> чей это дом? = чей это дом?

### 4.4. Рефлексивное притяжание: `свой`

`свой` указывает, что владелец — подлежащее своей клаузы.

| Пример | Перевод |
|---|---|
| он чита свой книга | он читает свою книгу |
| она дати друг свой адрес | она дала другу свой адрес |
| он чита книга у она | он читает её (чужую) книгу |

Без `свой` конструкция `у NP` описывает владельца, не обязательно совпадающего с подлежащим. Если владелец совпадает с подлежащим, норма — `свой`.

## §5. Прилагательное

### 5.1. Неизменяемость

Прилагательное имеет одну каноническую форму — полную форму мужского рода единственного числа именительного падежа. Оно никогда не согласуется:

> большой дом, большой машина, большой окно, большой люди

Форма `большой` здесь не маркирует мужской род: это словарная форма лексемы. Род, число и падеж в РУСИТ не выражаются.

### 5.2. Один тип

Качественные и относительные прилагательные сохраняют полную форму:

| Русский | РУСИТ |
|---|---|
| большой | **большой** |
| красивый | **красивый** |
| тихий | **тихий** |
| холодный | **холодный** |
| тёмный | **тёмный** |
| деревянный | **деревянный** |
| лесной | **лесной** |
| русский | **русский** |

Никакого усечения, классификации прилагательных или согласования.

### 5.3. Адвербиальная функция и наречия времени

Грамматического класса наречий нет. Прилагательное становится адвербиальным модификатором **по позиции** после глагола, сохраняя форму:

| Позиция | Функция | Пример |
|---|---|---|
| перед существительным | атрибут | тихий человек |
| после глагола | адвербиальный модификатор | он говори тихий |

Кроме того, существует **закрытый список наречий времени** (§1.2): `вчера, сегодня, сейчас, завтра, потом, всегда, никогда`. Это лексический, а не грамматический класс; новые элементы в него не добавляются.

> я вчера был чита книга = вчера я читал книгу  
> он никогда не чита этот книга = он никогда не читает эту книгу

### 5.4. Степени сравнения

| Степень | Средство | Пример |
|---|---|---|
| положительная | нулевой маркер | большой |
| сравнительная | более | более большой |
| превосходная | самый | самый большой |

Стандарт сравнения вводится союзом `чем`; пространственная среда сравнения — реляционным словом `среди`:

> я более высокий чем ты = я выше тебя  
> этот дом самый большой среди все дом в город = этот дом самый большой в городе

### 5.5. Краткие предикативы

Закрытый список кратких предикативов: **рад, должен, горазд, готов**. Список исчерпывающий; новые элементы не образуются. Это лексический факт: у этих слов нет полной прилагательной формы в предикативной функции.

> я рад  
> я должен иди  
> он горазд говори  
> я готов

Для слова `готов` словарь разводит две лексемы: предикатив **готов** и определение **готовый** (`готовый ответ`).

Модальные предикаторы §12 (`надо, можно, нельзя, нужно`) — отдельный закрытый класс. Два класса не пересекаются: `нужно` в список кратких предикативов **не входит**.

## §6. Числительное

### 6.1. Неизменяемость

Числительное не склоняется и не требует изменения существительного:

> один дом, два дом, три дом, сто дом

### 6.2. Составные числа

Числа строятся аналитически, от крупных разрядов к мелким. Разрядные слова: `десять`, `сто`, `тысяча`.

| Число | РУСИТ |
|---|---|
| 11 | десять один |
| 20 | два десять |
| 24 | два десять четыре |
| 100 | сто |
| 200 | два сто |
| 1000 | тысяча |
| 2024 | два тысяча два десять четыре |

### 6.3. Порядковые числительные

Порядковые значения выражаются через `номер`:

> номер один дом = первый дом  
> номер два этаж = второй этаж  
> номер пять линия = пятая линия

В устойчивых названиях допустимы словарные формы `первый`, `второй` и т. п. как заимствованные лексемы; это не грамматическая категория.

### 6.4. Дроби

> один из два = 1/2  
> три из четыре = 3/4  
> один из сто = 1/100

## §7. Глагол: время, вид, фаза

### 7.1. Неизменяемость

Глагол не изменяется по лицу, числу, роду, времени и наклонению.

> я говори, ты говори, он говори, мы говори

### 7.2. Время

Время маркируют только `был` и `буд`:

| Время | Маркер | Пример | Перевод |
|---|---|---|---|
| настоящее / неспецифицированное | нулевой маркер | я чита | я читаю |
| прошедшее | был | я был чита | я читал |
| будущее | буд | я буд чита | я буду читать |

### 7.3. Вид и завершённость

Вид маркируют граничные частицы; TAM-маркеры времени вида не выражают:

| Значение | Маркер | Пример | Перевод |
|---|---|---|---|
| несовершённый / процесс | нулевой маркер | я чита | я читаю |
| совершённый телический | кон | я кон чита | я прочитал |
| результат приобретения | получ | я получ зна | я узнал |
| результат утраты | перест | я перест люби | я разлюбил |

`кон` регулярно добавляет завершённость к общей лексеме вида пары; он не дублирует отдельную лексему.

### 7.4. Фаза

| Фаза | Маркер | Пример | Перевод |
|---|---|---|---|
| начало | нач | я нач чита | я начинаю читать |
| прекращение | пере | я пере чита | я перестаю читать |
| продолжение | прод | я прод чита | я продолжаю читать |

### 7.5. Прогрессив и экспериенциальность

| Категория | Маркер | Пример | Перевод |
|---|---|---|---|
| прогрессив | сей | я сей чита | я сейчас читаю |
| опыт | про | я про чита | я когда-то читал / я имел опыт чтения |

### 7.6. Мутатив

Мутатив — единственная в системе частица **ста** = «становиться» (imperfective). Perfective мутатива = **кон ста**. Частицы `станов` из предыдущих версий исключены.

| Значение | Конструкция | Пример | Перевод |
|---|---|---|---|
| процесс (imperfective) | ста | город ста тихий | город становится тихим |
| процесс прошедший | был ста | город был ста тихий | город становился тихим |
| переход (perfective) | кон ста | город кон ста тихий | город стал тихим |
| переход прошедший | был кон ста | город был кон ста тихий | город (к тому моменту) стал тихим |
| переход будущий | буд кон ста | она буд кон ста врач | она станет врачом |

Дисциплина разведения: `был`/`буд` несут **только время**, `кон` несёт **только завершённость**. Мутатив не имеет собственной perfective-формы; она порождается правилом.

### 7.7. Возвратность

Частица `ся` ставится после глагола:

> он умыва ся = он умывается  
> дверь открыва ся = дверь открывается

При объекте частица остаётся после глагола:
 
> она умыва ся = она умывается

### 7.8. Схема глагольной группы

```text
[не] [был | буд] [про | сей] [ГРАНИЧНАЯ] [ста] V [ся]
```

- `ГРАНИЧНАЯ` — не более одной частицы из множества `{кон, нач, пере, прод, получ, перест}`;
- слоты `[про | сей]` взаимоисключающие;
- схема читается вместе с ограничениями §21: недопустимые сочетания отклоняются семантическими правилами, а не списком ручных исключений;
- нулевые слоты не реализуются.

### 7.9. Позиции частиц фокуса и дискурса

Частицы уровней 2–3 не входят в §7.8. Общий принцип: фокусная частица ставится перед компонентом, на который распространяется её значение.

| Частицы | Позиция | Пример |
|---|---|---|
| уже, ещё | перед граничной частицей или перед V | он уже кон дела, я ещё чита |
| только, даж, имен, тож | перед фокусным элементом | только старик был сиди у дверь, даж он приходи |
| все | перед существительным или после подлежащего | все дом, они все иди |
| более, самый | непосредственно перед прилагательным | более большой, самый тихий |
| же | после первого элемента клаузы | я же говори, он же врач |

> он уже был кон чита книга = он уже закончил читать книгу  
> я только этот книга чита = я читаю только эту книгу

---

## §8. Императив

### 8.1. Принцип

Императивных суффиксов нет. Императив образуется синтаксисом.

| Лицо | Конструкция | Пример | Перевод |
|---|---|---|---|
| 2 ед. | V без подлежащего | чита! | читай! |
| 2 мн. | вы + V | вы чита! | читайте! |
| 1 мн. | да + мы + V | да мы чита! | давайте читать! |
| 3 л. | да + он/она/они + V | да он чита! | пусть читает! |

### 8.2. Отрицательный императив

> не чита! = не читай!  
> вы не чита! = не читайте!  
> да мы не чита! = давайте не читать!

### 8.3. Различение индикатива и императива

| Конструкция | Структура | Пример | Значение |
|---|---|---|---|
| индикатив | S + TAM + V | я говори | я говорю |
| императив 2 ед. | V без S | говори! | говори! |
| императив 1/3 л. | да + S + V | да он говори! | пусть говорит! |

Омонимия формы снимается контекстом и знаком препинания.

---

## §9. Отрицание

Частица `не` ставится перед тем компонентом, который отрицается.

В глагольной группе без модального предиката `не` стоит перед первым слотом глагольной группы:

> я не говори  
> он не был чита книга  
> мы не буд иди  
> я не кон дела работа  
> город не был ста тихий = город не становился тихим  
> город не кон ста тихий = город не стал тихим

### 9.1. Область отрицания с модальностью

С модальными предикаторами позиция `не` различает область отрицания:

| Конструкция | Отрицается | Перевод |
|---|---|---|
| не надо я иди | модальный предикат | мне не нужно идти |
| надо я не иди | действие | мне нужно не идти |
| нельзя ты входи | модальный предикат | тебе нельзя войти |
| можно ты не входи | действие | тебе можно не входить |

С именным предикатом:

> я не врач  
> она не красивый

## §10. Вопрос

### 10.1. Полярный вопрос

Частица `ли` стоит в начале вопросительной клаузы:

> ли ты люби этот книга?  
> ли он был дома?  
> ли вы буд иди?

### 10.2. Вопрос с вопросительным словом

`ли` не используется. Вопросительное слово стоит в начале клаузы:

> кто ты види?  
> что он дела?  
> где ты живи?  
> куда ты иди?  
> когда они буд иди?  
> почему ты не говори?

### 10.3. Встроенный полярный вопрос

`ли` открывает встроенную вопросительную клаузу:

> я не зна ли он буд приходи = я не знаю, придёт ли он

### 10.4. Встроенный WH-вопрос

`ли` не используется:

> я не зна кто он види = я не знаю, кого он видит  
> я спрашива куда они иди = я спрашиваю, куда они идут

---

## §11. Условие и сослагательность

Частица `бы` ставится после подлежащего:

> я бы иди = я бы пошёл  
> если я бы зна, я бы приходи = если бы я знал, я бы пришёл

### 11.1. Условные периоды

| Тип | Формула | Пример |
|---|---|---|
| реальное | если + индикатив, индикатив | если ты проси, я помога |
| нереальное настоящее | если + бы, бы | если я бы зна, я бы помога |
| нереальное прошлое | если + был, был | если я был зна, я был приходи |

Единая норма: в нереальном прошлом `бы` заменяется на `был`; сочетание **`был бы` нелегально**.

> если я был зна, я был приходи = если бы я знал, я бы пришёл

---

## §12. Модальность

| Конструкция | Пример | Перевод |
|---|---|---|
| надо + S + V | надо я иди | мне надо идти |
| можно + S + V | можно ты входи | тебе можно войти |
| нельзя + S + V | нельзя они говори здесь | им нельзя здесь говорить |
| нужно + S + V | нужно я иди | мне нужно идти |

С TAM модальный предикатор занимает начало предложения; глагольные частицы остаются в глагольной группе:

> надо я был иди = мне надо было идти  
> можно ты буд входи = тебе можно будет войти  
> нельзя они был говори здесь = им нельзя было здесь говорить

Инфинитивный поворот без эксплицитного подлежащего допустим:

> надо кон строи дом = надо построить дом  
> надо кон дострои дом = надо достроить дом  
> можно кон бери книга = можно взять книгу

**Норма запрета.** Единственная лексикализованная форма запрета — `нельзя`. Форма `не можно` — свободная комбинация частицы `не` с `можно`, семантически тождественна `нельзя`; обе легальны, различия в значении нет. В примерах спецификации используется `нельзя`.

Область отрицания — §9.1.

## §13. Реляционные слова

### 13.1. Инвентарь и функции

Каждое реляционное слово имеет отдельную функцию; синонимического дублирования нет. Список **закрыт**.

| Слово | Функция | Пример | Перевод |
|---|---|---|---|
| у | притяжание, обладание | книга у я | моя книга |
| от | источник, происхождение, отделение | письмо от мама | письмо от мамы |
| к | адресат, получатель, направление движения | я иди к дом | я иду к дому |
| с | инструмент, совместность | я пиши с ручка | я пишу ручкой |
| в | внутреннее место | в дом | в доме |
| на | поверхность, опорное место | на стол | на столе |
| из | исходный пункт движения | из город | из города |
| о | тема | говори о война | говорить о войне |
| би | агент пассива | строи би рабочий | построен рабочими |
| для | бенефактив, цель | подарок для ребёнок | подарок для ребёнка |
| без | отсутствие | чай без сахар | чай без сахара |
| до | предельная точка времени или пространства | до война, до дом | до войны, до дома |
| после | временное следование | после обед | после обеда |
| между | промежуток между двумя опорными точками | окно между дом | окно между домами |
| через | пересечение, прохождение, отсрочка | через улица, через час | через улицу, через час |
| среди | окружение, среда, множественный фон | среди много дом | среди домов |

Итого: **16 реляционных слов**.

Слова `под, над, за, перед, около` в систему **не входят**; соответствующие значения выражаются через `у` (`у стена` = у стены / подле стены) или `в` (`в верх` = наверху, по контексту) либо именными группами (`верх стол` = верх стола). Расширение списка — отдельное редакционное решение, не грамматическая операция.

### 13.2. Разграничения

| Пара | Различие |
|---|---|
| для / к | `для` = польза или цель; `к` = адресат движения или получатель |
| до / к | `до` = предел; `к` = направление |
| после / от | `после` = временное следование; `от` = источник или происхождение |
| между / среди | `между` = промежуток между опорными точками; `среди` = окружение в множественном фоне |
| из / от | `из` = движение изнутри или исходная точка; `от` = источник, происхождение, отделение |
| из / среди | `из` = исход движения; `среди` = статичное окружение |

### 13.3. Вложенное владение

> дом у брат у друг = дом брата друга

Связывание **левоассоциативно**: `X у A у B` = «X принадлежит A, который принадлежит B» = дом брата, который принадлежит другу, то есть дом брата друга. Для снятия двусмысленности допустима группировка паузами или скобками.

### 13.4. Дательный адресат

Адресат передачи или сообщения выражается через `к`:

> она дати подарок к я = она дала мне подарок  
> я пиши письмо к друг = я пишу письмо другу

## §14. Пассив

### 14.1. Конструкция

Пассив строится регулярно: пациент выносится в позицию подлежащего, агент маркируется `би`.

Общая схема:

```text
Пациент + TAM + [кон | получ | перест] + V + [би + Агент]
```

Граничная частица опциональна. Значения:

| Конструкция | Значение | Пример | Перевод |
|---|---|---|---|
| без граничной частицы | процессуальный / неопределённый пассив | книга чита би ученик | книга читается учеником |
| кон | завершённый пассив | дом был кон строи би рабочий | дом был построен рабочими |
| получ / перест | результативный пассив | ответ был получ зна би ученик | ответ был узнан учеником |

> дом был кон строи би рабочий = дом был построен рабочими  
> книга буд кон чита би ученик = книга будет прочитана учеником

### 14.2. Без агента

> дом был кон строи = дом был построен  
> книга кон чита = книга прочитана

### 14.3. Пассив с результативами

`би` отвечает за агента; `получ` / `перест` — за результативное значение. Это разные слоты и они совместимы.

> ответ был получ зна би ученик = ответ был узнан учеником  
> доверие буд перест люби би народ = доверие будет утрачено народом

По-прежнему действует правило §21.1: на один предикат — не более одной граничной частицы, поэтому `получ` не сочетается с `кон`, но сочетается с `би`.

## §15. Придаточные предложения

### 15.1. Изъяснительные

> я зна что он живи в Москва = я знаю, что он живёт в Москве

### 15.2. Относительные

Относительная клауза открывается `который` и сохраняет внутренний SVO с пропуском относительного элемента.

> человек который я люби = человек, которого я люблю  
> человек который люби я = человек, который любит меня

### 15.3. Замена причастий

Причастий нет; используется `который` + полная клауза:

> человек который сиди у окно = человек, сидящий у окна  
> дом который был кон строи в прошлый год = дом, построенный в прошлом году

### 15.4. Замена деепричастий

Деепричастий нет; используются `когда`, `и` или полные придаточные:

> она улыба и был кон иди в комната = она улыбнулась и вошла в комнату  
> когда он говори, все молчи = когда он говорил, все молчали

При одинаковом подлежащем допустима координация VP с общим TAM.

---

## §16. Порядок слов

### 16.1. Нейтральный порядок

```text
S — (временное обстоятельство) — TAM — V — O — X
```

> я вчера был кон чита этот книга в дом = вчера я закончил читать эту книгу дома

Если временное обстоятельство отсутствует, схема сводится к `S — TAM — V — O — X`.

### 16.2. Нарративный порядок

Темпоральное обстоятельство может выноситься в абсолютное начало:

> вчера я был чита книга в дом = вчера я читал книгу дома

### 16.3. Топикализация

Компонент может выноситься перед подлежащим без смены грамматической роли:

> этот книга я чита = эту книгу я читаю  
> у дверь старик был сиди = у двери сидел старик

Топик не получает падежного маркера; его роль определяется позицией и контекстом.

### 16.4. Жёсткие правила

- подлежащее предшествует глаголу;
- объект следует за глаголом;
- определение предшествует определяемому;
- низкие обстоятельства обычно следуют за объектом;
- темпоральное обстоятельство стоит после подлежащего или выносится в начало клаузы.

## §17. Союзы

Базовый закрытый список союзов — **12**:

> и, или, но, потому что, если, когда, пока, хотя, что, чтобы, чем, который

> я чита книга, потому что я люби книга  
> если ты буд иди, я буд иди с ты  
> жда! пока я буд готов = жди, пока я буду готов  
> я более высокий чем ты = я выше тебя

`чем` используется в сравнительных конструкциях (§5.4).

## §18. Связка и экзистенциальность

### 18.1. Именная связка

| Время | Связка | Пример |
|---|---|---|
| настоящее / неспецифицированное | нулевая | я врач, дом большой |
| прошедшее | был | я был врач, дом был большой |
| будущее | буд | я буд врач, дом буд большой |

Для мутатива временная оппозиция строится регулярно (§7.6):

> он был ста врач = он становился врачом  
> он кон ста врач = он стал врачом

### 18.2. Экзистенциальность

Экзистенциальная и посессивная конструкция строится служебной лексемой **есть** (§2.4):

> есть дом = есть дом / дом существует  
> у я есть дом = у меня есть дом

Отрицание экзистенциала — `не есть` / `у я не есть`:

> у я не есть время = у меня нет времени

Экзистенциальное `есть` омонимично лексеме `ести` «кушать»; различение — словарными статьями и контекстом.

## §19. Словообразование

### 19.1. Деривация разрешена

Словообразование не является грамматической операцией и потому не нарушает запрет на флексию.

> человек → человеческий → человечность  
> работа → рабочий → работник  
> читать → читатель

### 19.2. Флексия запрещена

> ✗ человека, человеком, о человеке  
> ✓ человек

## §21. Совместимость частиц

### 21.1. Граничное правило

> **На один предикат допускается не более одной частицы из множества `{кон, нач, пере, прод, получ, перест}`.**

Это единственное граничное правило. Оно автоматически запрещает все пары внутри множества; ручной список запрещённых комбинаций не нужен.

### 21.2. Семантические ограничения

| Ограничение | Причина |
|---|---|
| `про` несовместим с граничными частицами и `ста` | опыт не является ни граничным событием, ни мутативным переходом |
| `сей` несовместим с `кон` | прогрессив исключает завершённость |
| `сей` избыточен с `прод` | обе частицы указывают на незавершённое текущее продолжение |
| `получ` избыточен с `перест` | приобретение и утрата взаимоисключающие результаты |

**Мутатив и граничные частицы.** `ста` в граничное множество §21.1 **не входит**: это мутатив, а не граничная частица вида. Поэтому совместимы: **кон ста** = «стать» (perfective мутатива, §7.6), **получ ста** = «удаться стать», **перест ста** = «перестать быть». Формула «ста избыточна с кон/получ/перест» из версий 5.2–5.3 удалена как противоречащая §7.6.

### 21.3. Совместимость слотов

| Сочетание | Статус | Пример |
|---|---|---|
| был + ста | разрешено | он был ста врач = он становился врачом |
| буд + ста | разрешено | она буд ста врач = она будет становиться врачом |
| был / буд + кон ста | разрешено | город был кон ста тихий = город стал тихим |
| был / буд + граничная частица | разрешено | я был кон чита |
| не + любой допустимый слот | разрешено | я не был ста врач |
| граничная частица + ся | разрешено | он был кон умыва ся |
| получ / перест + би (пассив) | разрешено | ответ был получ зна би ученик |
| был + про | разрешено, контекстуально ограничено | я был про чита = я имел опыт чтения |
| сей + про | недопустимо в одной группе | слоты `[про \| сей]` взаимоисключающие, §7.8 |

Схема §7.8 — шаблон слотов; валидатор обязан применять также §21.1–§21.3.

## §26. Примеры

### Простые предложения

> я чита книга = я читаю книгу  
> он был сиди на окно = он сидел на окне  
> маленький котёнок был спи = маленький котёнок спал  
> человек приходи = приходит / приходил человек  
> один человек приходи = пришёл один человек  
> человек был кон иди = пришёл человек

### Времена и вид

> я был кон чита книга = я прочитал книгу  
> мы буд строи дом = мы будем строить дом  
> она не был кон иди = она не пришла  
> я буд кон бери книга = я возьму книгу  
> я кон чита книга = я прочитал / дочитал книгу (по контексту)

### Посессив и направление

> книга у брат = книга брата  
> я иди к дом = я иду к дому  
> она дати подарок к я = она дала мне подарок  
> подарок для ребёнок = подарок для ребёнка  
> он живи без деньга = он живёт без денег  
> дом стоя среди много дерево = дом стоял среди деревьев  
> у я есть дом = у меня есть дом

### Мутатив и результат

> город ста тихий = город становится тихим  
> город был ста тихий = город становился тихим  
> город кон ста тихий = город стал тихим  
> она буд кон ста врач = она станет врачом  
> я получ зна ответ = я узнал ответ  
> он перест люби она = он разлюбил её

### Сравнение

> я более высокий чем ты = я выше тебя  
> этот дом самый большой среди все дом в город = этот дом самый большой в городе

### Рефлексивное притяжание

> он чита свой книга = он читает свою книгу  
> она дати друг свой адрес = она дала другу свой адрес  
> он чита книга у она = он читает её (чужую) книгу

### Отрицание и модальность

> не надо я иди = мне не нужно идти  
> надо я не иди = мне нужно не идти  
> нельзя ты входи = тебе нельзя войти  
> можно ты не входи = тебе можно не входить  
> у я не есть время = у меня нет времени

### Императив

> чита! = читай!  
> вы чита! = читайте!  
> да мы иди! = пойдём! / давайте пойдём!  
> да он живи! = пусть живёт!  
> не чита! = не читай!  
> жда! пока я буд готов = жди, пока я буду готов

### Разговорная речь

> ну, типа, я не зна = ну, типа, я не знаю  
> кароч, мы иди = короче, мы идём  
> он прям уста = он прям устал  
> вобщем, всё плохой = в общем, всё плохо

### Пассив

> дом был кон строи би рабочий = дом был построен рабочими  
> ответ был получ зна би ученик = ответ был узнан учеником  
> книга чита би ученик = книга читается учеником
